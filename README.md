<h1 align="center">Tomapuntes</h1>

<p align="center">Leé tus apuntes en PDF, subrayá y descansá. Un tomate a la vez.</p>

<p align="center">
  <img src="docs/demo.gif" alt="Tomapuntes en 15 segundos: la entrada con el tomatazo, el resumen de lectura, la biblioteca, subrayar en un PDF y el calendario de parciales" width="880" />
</p>

- **Leé** tus PDFs de clase en una pantalla oscura, sin distracciones.
- **Subrayá** por colores; los subrayados quedan guardados dentro del PDF.
- **Concentrate** con un pomodoro con forma de tomate y sonidos para leer.
- **Organizá** tus parciales y TPs con fechas, notas y calendario.
- **Mirá tu progreso**: tiempo leído, racha y mapa de calor.

Funciona sin cuenta (todo queda en tu navegador) o con cuenta para tenerlo en todos tus dispositivos.

## Probarla

```bash
npm install
npm run dev
```

Para usar cuentas y la nube, copiá `.env.example` a `.env.local` con los datos de tu proyecto de Supabase y ejecutá `supabase/migrations/` en su SQL Editor.
